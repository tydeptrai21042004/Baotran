Current GitHub repos:
- https://github.com/tydeptrai21042004/whc-dt1d.git
- https://github.com/tydeptrai21042004/whc-vit.git

This supersedes the older thankthecoorp package with stale repo names/interfaces.

Policy: tables + reviewer ablations = seeds 0/1/2; training figures = exactly seed 0; ViT fair tables = 10 LR trials/method on tune seed 42 then final seeds 0/1/2 and one test evaluation at best-validation checkpoint. No test-set tuning.

New ViT results: V01 VTAB-DTD, V02 VTAB-EuroSAT. Existing manuscript ViT: V03 Flowers102 BS16, V04 Flowers102 BS32, V05 VTAB-Caltech101 BS32.

Every training script is fresh-session standalone, uses a 710-minute hard cap, and writes a resumable <SESSION>_results.zip. Heavy experiments are split by method, never by seed, so shared-LR-over-seeds remains intact. SVHN is split into exactly two files and each file uses both T4 GPUs concurrently. If Kaggle is slower and a session still time-caps, upload that session ZIP and rerun the same cell.

Run each .sh in a fresh Kaggle notebook with Internet ON and preferably 2xT4. Paste as a %%bash cell. After all sessions, upload all *_results.zip to one notebook and run FINAL_MERGE_ALL_RESULTS.sh.

For publication, pin one frozen Git commit across all sessions with DT1D_CNN_COMMIT or DT1D_VIT_COMMIT.

The current snapshots miss .zenodo.json; these cells validate scientific/protocol code and do not block training on archival metadata. Add .zenodo.json before the final GitHub/Zenodo release.


## v5 scope clarification

This bundle is built around the executable experiment contracts in the current `whc-dt1d` and `whc-vit` repositories and is intended to regenerate the numerical manuscript results that should survive the final revision, plus the two new ViT results requested by the author: VTAB-DTD and VTAB-EuroSAT. Static method-positioning tables do not require GPU reruns. Deterministic architecture/spectral Figures 2--3 are generated by `G00_static_figures_02_03.sh`. Legacy manuscript plots that are no longer represented by a current repository experiment contract (for example the old KTH-TIPS plot) are intentionally not invented here; either remove/replace them with the final supported Pareto figures or add a verified repository experiment before publication.

Every training `.sh` file is a complete fresh-session Kaggle cell: clone current GitHub -> optional commit pin -> install -> scientific/protocol validation -> dataset/weight preparation -> plan/dry-run -> train -> aggregate -> resumable ZIP. For sessions marked `part 1 of 2` / `part 2 of 2`, the method set is split across two independent Kaggle sessions while every method still keeps all final seeds 0/1/2 together.
